# 🌙 12 Rabi-ul-Awwal

A beautiful and respectful **Islamic-themed web project** created to commemorate **12 Rabi-ul-Awwal** and celebrate the blessed occasion of **Eid Milad-un-Nabi ﷺ**.

The project combines a simple, elegant interface with Islamic content and an interactive **Durood** feature, creating a meaningful digital experience through frontend web development.

## 📖 About The Project

**12 Rabi-ul-Awwal** is a dedicated Islamic web project created to mark the blessed occasion associated with the birth of **Prophet Muhammad ﷺ**.

The website presents Islamic-themed content in a clean and visually engaging layout. It also includes an interactive Durood feature implemented using JavaScript.

The purpose of this project is to combine **web development, creativity, and a meaningful Islamic message** in one simple digital experience.

## 📿 Durood Feature

The project includes a dedicated **Durood** functionality powered by JavaScript.

The `darood.js` file handles the interactive Durood-related functionality, making the website more engaging than a purely static page.
